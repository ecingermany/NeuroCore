## 1. 项目目标与当日共识

NeuroCore 将承载可安装、可版本化依赖的 Python EEG 核心算法，供报告工具、桌面应用、服务端及其他相关工具复用，减少手工复制造成的算法漂移。

按用途区分两条主体线路：

1. **官方测评报告线路**：BQtester 的睁眼／闭眼静态测评、三项一分钟动态测评，以及 BQRequest 报告指数计算，均属于生成官方报告的流程。
2. **神经反馈训练线路**：独立安装版 MonitorR 用于日常神经反馈训练，包含频谱指标、自适应阈值、奖励判定和状态管理。

另设 YYG 扩展分析；可视化展示对应算法输出，不负责暗中决定算法口径。两条主体线路可放在同一个 Python 包中，不需要因此拆成两个发行包。

**重要纠正**：不能将 BQtester 动态测评归为日常训练线路，也不能将独立 MonitorR 简单归为绘图工具。BQtester 内附的 MonitorR 与独立 MonitorR 是不同二进制版本，输入、窗函数及状态生命周期应分别记录。

语音中的“Monitor 2”在本次讨论中已由用户确认为 MonitorR；“Bringsy”按 BrainSee 理解。MeasureR 是另一个用于测量／频谱展示的程序，不与 MonitorR 混称。

## 4. 数据链与职责

设备发送双通道时域整数，不发送 FFT 或三维矩阵。

~~~text
设备时域采样
├── 官方测评
│   ├── 静态 O1/C/O2：首次睁眼、闭眼、再次睁眼，各 30 秒
│   ├── 动态放松/注意/集中：各 60 秒，计算 P/W
│   └── BFN → BQRequest → BAN → BrainSee 报告/图表
├── 独立 MonitorR 神经反馈
│   └── 输入适配 → FFT → 指标 → 阈值 → 门控 → 奖励 → 训练反馈
└── YYG 扩展分析及相应可视化
~~~

BFN 保存阶段时域数据、资料及已有训练 P/W；不应理解成把三维图数值保存成报告。报告指标和报告三维图可以分别对数据计算，不能因出现在同一报告中就认为使用相同 FFT 链。

## 5. 增益表：本日最重要的术语修正

YYG／网页静态链确实对单个频点应用以下显示增益：

| 半开频率区间 Hz | 增益 |
| --- | ---: |
| [0,2) | 0.40 |
| [2,4) | 0.31 |
| [4,8) | 0.24 |
| [8,12) | 0.21 |
| [12,20) | 0.20 |
| [20,30) | 0.15 |
| 30 Hz | 0 |

第一份交接将其称为“官方增益表”；第二份后续证据修正了这种归属。MeasureR 面板相近的经验比例，可由统一 FFT 缩放和不同宽度频带的 RMS 解释，无需额外加六个乘数。

因此：

- 保留 YYG 既有系数与行为，避免历史数值漂移。
- 命名为 YYG 显示增益，不宣称是已从官方程序恢复的六段增益。
- 不将它添加到 MonitorR、BQtester 或 BQRequest 的兼容链。
- 原始码值、FFT 幅值、频带 RMS、颜色值、功率／PSD、物理电压分别定义。
- 当前物理电压标定未完成；软件 mV 标签不能替代标定证据。

## 6. 必须分别保留的频谱路径

| 路径 | 已知配置与数学 | 状态 |
| --- | --- | --- |
| MeasureR 默认回放 | N256；(raw−511)×50/512；periodic Hann；abs(FFT)×16/N；DC=0；面板另算 RMS | 代码及人工信号验证 |
| 独立 MonitorR | 已验证设备适配为接收 256 点、FFT128；periodic Hann；有配置相关幅值转换 | 指标、历史、奖励及部分界面逐格验证 |
| BQtester 配套 MonitorR | 本日实测 N256、范围1024、无窗；abs(FFT((raw−511)×100/1024))/16；DC=0 | 一次真实会话三项 P/W 匹配 |
| BQRequest 报告指数 | N256；(raw−511)×50/512；periodic Hamming；幅值除16；DC=0 | 20 组 BFN/BAN 指标验证 |
| BrainSee 默认三维绘图 | 静态证据支持无窗；N256 幅值乘1/16 | 尚未完成同输入逐点显示验证 |
| YYG／网页静态显示 | 整段去趋势→陷波→带通→分帧去均值→对称 Hann→单边幅值补偿→显示增益→4倍频率插值 | 两端完整逐点等价仍需审计 |

独立 MonitorR 的输入适配在已验证路径中，将相邻原始值按整数位移和除法转换到前128槽，后128槽保留接收原值；FFT与门控读不同范围。128点TXT不足以恢复完整门控，不能补零假造原始上下文。

关于 MonitorR 幅值表达式，交接中同时保留了已验证指标重建模型（processed−511、乘50/512、FFT乘0.5）和读取实际范围字段的底层表达式。相关奖励频点可等价，不代表所有低频点也相同。以后若把完整频谱作为显示标准，必须核对全频点、范围参数及实际输入，不能仅以奖励一致代替。

YYG／网页使用累计整段正反向滤波，新增数据可能改变历史频谱；不是固定延迟的因果流式算法。离线全文件回放与实时中途显示不保证逐点相同。插值后的0.25 Hz绘图间距不增加原生1 Hz频率分辨率。

## 7. BQtester 动态测评：本日新增验证结论

### 7.1 取代旧状态的发现

旧记录曾用 Hamming 窗测试六种输入／历史方案，未复现旧20组、60项P/W。那是候选试验，不能当成已验证的独立 MonitorR 算法与 BQtester 的最终等价性测试。

新版附录 D0 记录：**当前 BQtester 配套 MonitorR 训练实际无窗**。一次真实头带会话中，从原始 EEG 经 FFT、动态阈值、奖励序列重算的放松／注意／集中 P/W 均与 BFN 保存值匹配。

- 482份状态快照中，477份双读一致快照的双通道FFT全部匹配。
- 最大绝对误差约4.40×10^-14；双读一致不等于原子采样。
- 三次进程启动／退出证实三项各自冷启动。
- 三项各60块的P/W匹配。
- 不能据此声称旧20组已重验、全部屏幕格子已独立核验，或两个 MonitorR 版本已等价。

### 7.2 特征、阈值、奖励

以下频点范围包含两端：

~~~text
X = 双通道9…18频点均值
S = B通道12…15均值
Beta = A通道16…18均值
T = 双通道4…7均值
H = 双通道19…48均值

m_h = sum(F_h[4…29])/25
d_h = 0.2*sqrt(sum((F_h[k]−m_h)^2)), k=4…29
R = 50*[ln(0.94+c*d_A)+ln(0.94+c*d_B)]
c = 0.03167420814479638
~~~

取26点却除25是恢复的原行为，不改成标准差。

每个特征保存三槽历史、阈值与计数；第4、7、10…次用旧三项更新，当前值进入新组。奖励下限=(均值+最小值)/2，抑制上限=(均值+最大值)/2；初始阈值为零。每项测评清空完整状态，不只是阈值标量。X奖励下限与X抑制上限独立。

| 模式 | 严格比较条件 |
| --- | --- |
| 放松1 | X高于奖励下限，R低于抑制上限 |
| 注意4 | S高于下限，T和H低于各自上限 |
| 集中2 | Beta高于下限，T和X低于各自上限 |

另需启用标志及原始门控。bad为两通道完整256点中小于10或大于1013的总数：

~~~text
gate = (bad < 128) OR (bad >= 224)
reward = 模式条件 AND 启用 AND gate
~~~

这是非单调兼容规则，不将其包装成新的通用伪迹处理标准。

### 7.3 P、W、SRQ

~~~text
P = floor(100*成功格数/60)
W = sum(r[t−1]*r[t]), t=2…60
  = 每段连续成功长度L贡献max(L−1,0)

T_i = P_i+W_i
SRQ = max(0, sum(T)−std_population(T)−(max(T)−min(T)))
~~~

SRQ下游公式已有20组BFN/BAN对照；本日新增的是当前版本一次会话的EEG到三项P/W匹配，不将二者合写成20组上游已全部验证。

用户报告 BQtester 存在现场格子与最终报告格子有时不同的已知现象。本日未独立复现或定位该现象，也不将旧候选失败全部归因于它。屏幕逐格一致、存档P/W一致和报告SRQ一致是三个不同层级。

## 8. 官方报告指标清单与边界

已复原BRQ、Rate、Tension/PhysicalStress、Distraction/MentalStress、ATQ、ACQ、EQ、AntiStress、Symmetry、Synchrony、CQ、SRQ、BQ，以及强度、左右差、倾向标签、LogBand和三类Slope。

| 指标／数据 | 核心定义或容易混淆点 |
| --- | --- |
| BRQ | 闭眼逐秒局部峰计数、年龄附近选峰、幅度比及Alpha衰减率加权，不是平均谱简单最大峰 |
| Rate | 逐秒Theta/SMR比值的90秒平均，不是全程均值相除 |
| ATQ／ACQ | 特定比值、分段对数变换、年龄参数及其他项组合 |
| Tension／Distraction | O2指定低频／高频幅值 |
| EQ | 闭眼逐秒Alpha左减右，结合BRQ和ATQ，不与YYG EQ直接合并 |
| Synchrony | 每秒时域Pearson相关的90秒平均，不是coherence |
| Symmetry | O2/C两阶段六频段左右比值先平均，再做对称变换 |
| CQ | Symmetry+25*(Synchrony+1) |
| BQ | 11项分量平均 |
| Relative Strength | 特定闭眼频段幅值，不是教科书相对功率百分比 |
| LogBand | mean(log(幅值))，不是log(mean(幅值)) |
| Slope | 频段序号间隔差分，不是以Hz拟合的1/f斜率 |

逐秒六频段为1–3、4–7、8–12、12–15、16–20、21–30；跨秒均值缓冲实际偏移为2–4、5–8、9–13、13–16、17–21、22–31。保留重叠及偏移。

年龄参数支持文档恢复的4–99岁分组，不将其外推到0–3岁或100岁以上。完整年龄表、选峰及全部公式以交接算法正文为准。

20组主要指标最大绝对误差约5×10^-5，与BAN文本精度相符；Synchrony约5×10^-7。额外LogBand约5×10^-6、Slope约3.62×10^-6，活性／情绪标签20/20匹配。这些不等于全部JPG像素和数值均已逐项验证。

BFN/BAN研究解码涉及RSA包装、Triple-DES CBC及载荷压缩；当前研究解码器未验证签名真实性。格式适配和纯数学分层，不直接将研究脚本当生产级不可信文件解析器。

公式复现与临床效度分别记录；Positive/Negative、Depress等保留为软件标签，不自动翻译成诊断结论。

## 9. 三维FFT：BQtester、BrainSee、MeasureR的区别

- **BQtester测评时实时三维图**：具体运行窗与绘图路径仍未独立确认。本日“训练无窗”不能自动推广到全部实时三维图。
- **BrainSee报告三维图**：默认无窗有强静态证据；与MeasureR同输入逐点及像素显示对照未完成。
- **MeasureR三维图**：已分析默认periodic Hann，N256时幅值乘1/16；面板RMS和曲面顶点是不同数值。
- **BQRequest报告指数**：Hamming链，不因为BrainSee绘图无窗而改变。

同一人工信号：N256、10 Hz、原始正弦峰值30码，无窗主峰23.4375、Hann11.71875、Hamming12.65625。这不是任意真实波形的固定倍率换算。

MeasureR曲面颜色按相邻两帧、相邻两频点四个顶点幅值平均后选色。颜色、顶点峰高和面板RMS不能互相替代。BrainSee色阶、裁剪、透视和所有边界尚未完整恢复。

## 10. Python包的设计方向

以下为讨论形成的方向；具体目录、API命名和第一版范围尚待实施设计，不代表代码已经落地。

~~~text
neurocore/
  data/                 原始记录、阶段、配置、校验
  official_bq/
    assessment/         静态/动态测评组织所需纯算法与P/W
    report/             BQRequest兼容指数
  neurofeedback/
    monitor/            独立MonitorR指标、阈值、门控和奖励状态
  analysis/
    yyg/                YYG既有频谱与扩展特征
  visualization/        显示口径、网格与绘图数据；渲染可选
~~~

原则：

1. 共享基础FFT、窗口等工具实现，各路径显式指定参数和处理顺序。
2. 官方测评、独立训练、YYG分析按版本和口径区分；不因函数同名就合并。
3. 结果附算法标识、版本、配置、阶段和状态上下文；区分A/B设备通道与实际左右映射。
4. 保存完整时域原始数据及必要历史；不将显示增益后的频谱反写为原始EEG。
5. 工具依赖核心；核心不依赖GUI、CLI、报告模板、建议库或品牌资源。
